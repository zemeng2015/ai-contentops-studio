# Product Requirements

## Problem

Technical professionals need a repeatable way to turn AI engineering signals into credible,
source-grounded content that strengthens a portfolio and can be reviewed before publishing.

## Users

- Applied AI engineers building a public portfolio
- Platform engineers publishing internal AI engineering digests
- Technical leads turning research into team-facing notes

## MVP

- Create a content run from a topic
- Persist research, outline, draft, evaluation, and trace artifacts
- Publish generated HTML to a static site target when evaluation passes
- Expose API and CLI interfaces
- Run deterministic tests without external API keys

## Non-goals

- Multi-tenant SaaS billing
- Automatic social media posting
- Fully autonomous publishing without review controls
- Heavy agent framework dependency
